# PISA 2025 Viz
This is a project that attempts to visualize data from [PISA 2025](https://www.oecd.org/en/publications/2026/09/pisa-2025-results-volume-i_5265bfb1.html) in a way that draws attention to and invites exploration of the AI-related parts: how AI usage varies and correlates with factors such as student performance and socio-economic status.

## Development
This is a [Vite](https://vite.dev) project built with the TypeScript+React template. All the application code is in `/src`. The application relies on the file `src/pisa_data.json`, which is a processed version of the PISA data generated by scripts in `/scripts`. When making changes to the scripts, run `npm run build:data`, commit the updated `src/pisa_data.json`, and update any code that uses the file.

### Running the site
Install dependencies and start the dev server:

```sh
npm install
npm run dev
```

### Regenerating the data
1. Download the spreadsheets listed in [`scripts/data/README.md`](scripts/data/README.md) into `scripts/data/`. They're gitignored.
2. Run `npm run build:data`, which reads the spreadsheets and builds `src/pisa_data.json`.
3. Check the diff of `src/pisa_data.json`, update any code that uses it, then commit it. If some numbers changed, it may mean your spreadsheet versions were different than the ones used to generate the previous one (this may be intended).

## About PISA
PISA (Programme for International Student Assessment) is an assessment of 15-year-olds in school run by the OECD (Organization for Economic Co-operation and Development). It's run every three years and 2025 is the ninth run. 91 countries and economies took part: 38 OECD members and 53 partners, 85 of which (all 38 OECD members and 47 partners) have data on students' AI use. The results came out in September 2026.

Each sampled student takes a test in science (PISA's main focus), mathematics and reading, plus a new Learning in the Digital World assessment. Students also fill out a questionnaire about their background, their school and how they learn. PISA 2025 is the first one to ask students about AI.

### Navigating the PISA data
The OECD published PISA 2025 in three layers, from most to least processed: the report, the Excel tables behind it, and the raw database. Turning the raw data into correct country numbers takes careful statistics, and the OECD has already done that work in the Excel tables. So we use the OECD's numbers wherever we can, rather than recomputing them from the database and risking mistakes.

#### 1. The full report
[PISA 2025 Results (Volume I)](https://www.oecd.org/en/publications/2026/09/pisa-2025-results-volume-i_5265bfb1.html) is the OECD's written analysis. We can read it for context and the OECD's interpretations. Chapter 4 is of special interest as it covers AI usage and student performance in relation to it.

#### 2. The OECD Excel tables
The charts and tables in the OECD's report come with a downloadable Excel file. All the interesting statistics are here: each country's average AI usage levels, how science scores differ between students who use AI often and those who don't, and how AI use differs between socio-economically disadvantaged and advantaged students. These are all things this project aims to visualize.

#### 3. The raw data
The [PISA 2025 database](https://www.oecd.org/en/data/datasets/pisa-2025-database.html) has one row per student (and separate files for schools and teachers). We should only use it if we want some statistic not already in the Excel files. For example, the Excel tables surprisingly *only* have science (and computational problem solving) scores by AI use and not math or reading. The questionnaire compendia do have math and reading scores by AI use, but only unadjusted, so if we want them adjusted for socio-economic background we'd have to calculate them ourselves.

#### Other useful materials
Everything can be found on the [PISA 2025 page](https://www.oecd.org/en/publications/2026/09/pisa-2025-results-volume-i_5265bfb1.html) and the [database page](https://www.oecd.org/en/data/datasets/pisa-2025-database.html):

- **Technical report**: how the survey was run and how numbers are calculated. It also explains what all the files and supporting materials are. Still technically in draft phase as of November 13, 2026.
- **Codebook**: what every variable means and what its codes are.
- **Questionnaire compendia**: the OECD's own summary of every questionnaire question, country by country. They're computed from the raw database (with standard errors) so that people using it can check their own calculations. 
- **Student questionnaire** (PDF): the exact questionnaire administered to students.

### The AI data
PISA 2025 asks about AI in a few questions, spread across three questionnaires. The main student questionnaire reaches all 85 countries and economies with AI data, but the ICT and parent questionnaires were optional and only some countries ran them, so this project is interested primarily in the AI questions in the main questionnaire:

| Variable | Question | Questionnaire | Countries with data |
| --- | --- | --- | --- |
| `ST438Q01DA` | How often students use AI chatbots for school work to summarise a text they had to read | Student (main) | 85 |
| `ST438Q02DA` | ...to do preliminary research on a new topic | Student (main) | 85 |
| `ST438Q03DA` | ...to draft texts for writing assignments | Student (main) | 85 |
| `ST438Q04DA` | ...to help them learn | Student (main) | 85 |
| `ST436Q16DA` | How often students assessed the quality of AI chatbot output in lessons | Student (main) | 85 |
| `IC170Q10DA`, `IC171Q10DA` | How often students use AI tools at school / outside school | ICT (optional) | 44 |
| `IC182Q05DA` | Interest in learning about machine learning and AI | ICT (optional) | 44 |
| `PA205Q13DA` | Parents' ability to judge the quality of AI chatbot output | Parent (optional) | 18 |

The OECD combines the four `ST438` questions into one index, `AIUSESCH` ("students' AI use at school"), scaled so that the OECD average is 0 and the standard deviation is 1 (PISA 2025 Technical Report, Chapter 22). We can interpret it, with a grain of salt, as a measure of how often students use AI in a given country. Countries above 0 use AI for school work more than the average OECD country, and countries below 0 use it less. This is the primary data variable on the map. `ST436Q16DA` is also of future interest to map.

### Gaps/caveats
- **No AI data:** 6 of the 91 participants (Cambodia, Dushanbe, Kurdistan Region, Mauritius, Rwanda and Zambia) have no AI data. Importantly, they're "no data", not zero.
- **Sampling caution:** 6 of the 85 countries with AI data (Albania, Canada, the Netherlands, New Zealand, Norway and the United States) didn't meet PISA's sampling standards.
- **Not all country codes are ISO3:** PISA's codes are mostly standard ISO3, but 7 aren't: B-S-J-Z (China) `QCI`, Cyprus `QCY`, Dushanbe (Tajikistan) `QTJ`, Kosovo `KSV`, Kurdistan Region (Iraq) `QKI`, Chinese Taipei `TAP` and Ukrainian regions (17 of 27) `QUA`. The map can't place these, so `scripts/build-data.ts` swaps them for ones it can (e.g. `QCI` → `CHN`).
